# Práctico 1 – Maquetando con Flexbox

## Cómo abrir el proyecto
1. Descomprimí el archivo ZIP.
2. Abrí la carpeta `Practico1_Flexbox`.
3. Hacé doble clic en `index.html` para ver la página en el navegador.

## Archivos
- `index.html`: estructura y contenido de la página.
- `style.css`: estilos, distribución con Flexbox y adaptación responsive.
- `app.js`: interacción sencilla del menú.

## Flexbox utilizado
- `.nav`: `display: flex`, `align-items` y `justify-content` para distribuir el encabezado.
- `.hero-inner`: alinea el texto y la ilustración horizontal y verticalmente.
- `.services`: `display: flex`, `flex-wrap` y `gap` para ordenar las tarjetas.
- `.gallery`: `display: flex` y `flex-wrap` para crear la galería de imágenes.
- `.contact-inner` y `.footer-inner`: distribuyen y alinean sus elementos.

## Publicación en GitHub Pages
1. Creá un repositorio en GitHub.
2. Subí `index.html`, `style.css`, `app.js` y este README.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. Esperá a que GitHub Pages publique el sitio y abrí el enlace que aparece en esa sección.

Las fotografías de la galería se cargan desde Unsplash, por lo que se necesita conexión a Internet para verlas.
